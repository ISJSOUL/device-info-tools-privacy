# Privacy policy — Device Info & Tools

Hosts the privacy policy for the **Device Info & Tools** Android app
(`com.Deviceinfo_tools`) as a single static page.

This repository exists separately from the app source so the policy can be
served by GitHub Pages, which requires a public repository on the free plan,
without opening the application source alongside it.

The published URL is submitted to Google Play Console under both
**Store listing → Privacy policy** and **App content → Data safety**, so it must
stay reachable for as long as the app is listed.

Edit `index.html` and push to update; GitHub Pages redeploys automatically.
